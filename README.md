# Evaluating gender bias in languages with no morphological gender
This repository contains materials of the research on gender bias in languages with no morphological gender, conducted as part of the NLP course by Veronika Tsareva and Dmitriy Volyanskiy.
## Structure
The structure of the repository is as follows:
```
├── annotated_results
├── data
├── raw_results
├── README.md
├── main.ipynb
└── utils.py
```
The directories `data`, `raw_results`, and `annotated_results` contain the prompts, the models' responses, and their annotations, respectively.

The module `utils.py` was used to generate the prompts and preprocess the responses.

In the notebook `main.ipynb`, we received the responses and visualized the results of our experiments. This notebook provides all the information needed for reproducing the experiments.
